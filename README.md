# 灯下 · 一个没有名字的村子

一款**单机中文文字互动（互动小说 / 文字冒险）网页游戏**。纯前端、零依赖、零联网，双击 `index.html` 即可在浏览器里玩。

> 你在一座破庙里醒来，记得自己的名字，却想不起自己是谁。
> 走三里路，是一个村子——村里没有一个活人，只有满墙的红灯笼。

---

## 怎么玩

1. 双击打开 `index.html`（Chrome / Edge / Firefox 任一即可）。
2. 第一次进入会自动弹出「说明」，点「开始」关掉。
3. 读正文，点下面的选项推进剧情。**点击正文**可以跳过逐字显示。
4. 顶栏：`存档` / `读档` / `状态` / `说明`；底部 `从头开始`。

### 三条数值

| 数值 | 含义 | 归零后果 |
| --- | --- | --- |
| **命灯** | 你的阳寿 | 灯灭（立即结束） |
| **心魂** | 你的心神 | 失魂（立即结束） |
| **察觉** | 你看见了多少不该看见的东西 | 不致命，但**决定你能问出真话、看见暗门、拿到好结局** |

* 选项后面括号里是这道选项会用到的道具，或**未满足的条件**（灰色不可点）。
* 道具会解锁新分支；`状态` 面板能看道具说明、已见结局、最近的选择。
* 存档写在浏览器本机（`localStorage`），三格可覆盖，结局图鉴跨存档保留。

### 六种结局

| 结局 | 大意 | 提示 |
| --- | --- | --- |
| **灯灭** | 命灯耗尽 | 把名字交给山道上那个道士最省事 |
| **失魂** | 心魂耗尽 | 一路挑最"看不得"的选项 |
| **留名** | 你成了下一个守灯人 | 石案前那个凹痕，是量着你的尺寸做的 |
| **无名** | 你活下来了，但不再是你 | 名字给出去，换别人自由 |
| **出村** | 把一个村子从灯下还给白天 | **最好的结局**，需要察觉与关键道具 |
| **雾中** | 什么都没解决，活成了普通人 | 在祠堂里选择什么都不写 |

> 想看"最好的那个结局"：尽量把村子四处（义庄 / 祠堂 / 药铺 / 客栈）都走一遍拿到道具，
> 察觉攒到 6 以上，然后在祠堂与千灯之厅里选"把账做平"的那条路。

## 想改剧情 / 界面

改**界面排版** → 改 `<style>` 里的 CSS。
改**剧情选项** → 改 `SCENES.xxx = {...}`，格式：

```js
SCENES.s1_inn = {
  title:"一 · 有间客栈",                       // {name} 会替换成主角名
  text:"……正文，\n\n 分段，>> 是提示，!! 是得失，# 是居中口号……",
  enter:function(){ applyEffects({ins:1, give:"tongjing", flag:{metInn:true}}); },
  choices:[
    { text:"「住店。」", to:"s1_stay" },
    { text:"翻开柜台下的暗格", req:{ins:3}, use:"察觉 ≥ 3", to:"v_kezhan" },
    { text:"把铜镜举起来照他", req:{item:"tongjing"}, to:"s1_mirror", danger:true }
  ]
};
```

| `choices[]` 字段 | 含义 |
| --- | --- |
| `text` | 选项文字 |
| `to` | 目标节点名，或返回节点名的函数 |
| `act` | 点击时先执行的动作 |
| `req` | 显示条件：`{item, notItem, ins, flag, notFlag, flagText, notFlagText}` |
| `use` | 满足条件时括号里的提示 |
| `danger` | 红色警示样式 |
| `hide` | 为真则整个选项不显示（与灰色锁定区分） |

`applyEffects({...})` 支持：`hp`（命灯）、`sp`（心魂）、`ins`（察觉）、`give` / `take`（道具）、`flag`（剧情标记）、`log`。

改**机制**（数值、存档、打字机、标记语法）→ 改 236–613 行的引擎部分。

## 自检脚本（可选）

三个 Node 脚本，用迷你 DOM 桩把游戏跑起来做自动校验（不需要浏览器、不需要装依赖）：

```powershell
cd ink-lamp-game\tools
node verify.mjs      # 结构校验：分支目标是否存在、正文是否为空、道具引用是否有效
node routecheck.mjs  # 路线校验：逐节点点击，六条路线走通全部六种结局
node playtest.mjs    # 端到端：点击流、打字机、存档/读档、弹窗、低数值兜底
```
